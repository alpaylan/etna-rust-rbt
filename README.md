# etna-rust-rbt

RBT property-based testing workload for
[Etna](https://github.com/alpaylan/etna-cli) (Rust).

Depends on [`etna-rs-utils`](https://github.com/alpaylan/etna-rs-utils)
(shared Rust helpers) via a regular Cargo git dependency.

## Usage

```
etna experiment create my-exp
etna workload add https://github.com/alpaylan/etna-rust-rbt
```
